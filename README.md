# ✍️ Handwritten Digit Recognition using Keras

My first **Deep Learning** project — building an **Artificial Neural Network (ANN)** using TensorFlow and Keras to recognize handwritten digits from the MNIST dataset, while applying regularization techniques to improve model generalization.

## 📌 Overview

This project marks my first step into **Deep Learning** after learning traditional Machine Learning algorithms. Using the MNIST handwritten digit dataset, I built, trained, and evaluated a feedforward Artificial Neural Network (ANN) capable of classifying handwritten digits (0–9).

The project follows a complete deep learning workflow, from data preprocessing to model evaluation and performance improvement using regularization techniques.

The project covers:

- Loading and exploring the MNIST dataset
- Data preprocessing and normalization
- Flattening image data
- One-hot encoding class labels
- Building an Artificial Neural Network (ANN)
- Training the model using TensorFlow/Keras
- Evaluating model performance
- Visualizing predictions
- Improving the model using Dropout, L2 Regularization, and Early Stopping
- Comparing the performance of the original and regularized models
